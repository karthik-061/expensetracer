========================================================================
             EXPENSE TRACKER SYSTEM - RUN & SETUP GUIDE
========================================================================

Prerequisites:
  - Node.js (v18.x or later recommended)
  - npm (v9.x or later)
  - (Optional) Docker

------------------------------------------------------------------------
Option 1: Quick Run with Node.js
------------------------------------------------------------------------

1. Open your terminal and navigate to the project directory:
   cd expense-tracker-system

2. Install dependencies:
   npm install

3. Launch the server:
   npm start
   (or for live auto-reload during development: npm run dev)

4. Open your web browser and visit:
   http://localhost:3000


------------------------------------------------------------------------
Option 2: Run with Docker
------------------------------------------------------------------------

1. Build the Docker container image:
   docker build -t expense-tracker-system -f DockerFile .

2. Run the Docker container:
   docker run -d -p 3000:3000 --name expense-tracker-app expense-tracker-system

3. Open in browser:
   http://localhost:3000

4. Stop container when finished:
   docker stop expense-tracker-app && docker rm expense-tracker-app


------------------------------------------------------------------------
Data Storage:
------------------------------------------------------------------------
- Expenses data:   expenses.json
- Budget limits:   budget.json

All data changes made through the web interface are automatically persisted
to the local JSON files in real-time.
